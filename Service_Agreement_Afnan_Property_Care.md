## 2. SCOPE OF SERVICES
Party B shall provide full-stack web development, SEO, performance optimization, and digital marketing tracking services for Party A's website (`maresidentialpropertycareservicellc.com`), including but not limited to:

1. **Web Application & Infrastructure Development:**
   - Full-stack web application development, maintenance, and bug fixes using React, Vite, Node.js, and Express.
   - Hostinger server configuration, Apache `.htaccess` rule optimization, Gzip compression, and caching setup.
   - Prerendering setup via Puppeteer for static HTML generation and speed optimization.

2. **Search Engine Optimization (SEO) & Google Compliance:**
   - Implementation of technical SEO standards (Title tags, Meta descriptions, Canonical URLs, Semantic HTML5, Sitemap XML, Robots.txt).
   - Favicon & Web Application Manifest (`site.webmanifest`) integration for search engine indexing.
   - Google Search Console domain verification, URL inspection, and indexing request management.

3. **Performance & Speed Optimization:**
   - Mobile and desktop page speed optimization to achieve target performance metrics on Google PageSpeed Insights.
   - Non-render-blocking font loading, image compression (WebP/AVIF), asset minification, and code splitting.

4. **Analytics & Conversion Tracking:**
   - Google Tag Manager (GTM), Google Analytics 4 (GA4), and Meta Pixel integration.
   - Custom event tracking for phone clicks (`phone_click`), WhatsApp interactions, and lead conversion forms.

5. **Ongoing Technical Support:**
   - Security updates, SSL/HTTPS maintenance, content updates, and continuous site performance monitoring.
